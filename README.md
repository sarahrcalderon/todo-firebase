📋 Todo Firebase - Lista de Tarefas com Autenticação


Sobre o Projeto
Uma aplicação web moderna de lista de tarefas (To-Do List) com autenticação de usuários, desenvolvida com **React** e **Firebase**. O projeto permite que usuários se cadastrem, façam login e gerenciem suas tarefas de forma intuitiva e em tempo real.

### 🎯 Funcionalidades

- ✅ **Autenticação completa** com Firebase (cadastro, login, logout)
- ✅ **CRUD de tarefas** (Criar, Ler, Atualizar, Deletar)
- ✅ **Tarefas por usuário** - cada usuário vê apenas suas tarefas
- ✅ **Filtros** - Todas, Ativas e Concluídas
- ✅ **Barra de progresso** - acompanhe seu progresso em tempo real
- ✅ **Edição de tarefas** - edite o texto diretamente na lista
- ✅ **Design responsivo** - funciona em desktop, tablet e mobile
- ✅ **Ícones profissionais** com React Icons
- ✅ **Indicador de força de senha** no cadastro
- ✅ **Perfil Admin** - usuários com email específico têm permissões especiais
